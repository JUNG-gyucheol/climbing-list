# Climbing List

클라이밍 루트/문제 기록 및 영상 촬영 앱

## 기술 스택

- **Next.js 15** (Turbopack)
- **React 19** / TypeScript
- **Supabase** (백엔드/DB)
- **React Three Fiber** / GSAP (3D/애니메이션)
- **Tailwind CSS 4**
- **OpenAI API**
- **PWA** 지원

## 주요 기능

- 클라이밍 루트/문제 목록 관리
- 영상 촬영 및 기록
- 3D 시각 효과 및 애니메이션
- OpenAI 연동 기능
- PWA로 모바일 설치 가능

## 실행 방법

```bash
pnpm install
pnpm dev
```
